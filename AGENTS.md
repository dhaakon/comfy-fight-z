# Hackathon project instructions

- Keep generation sources in `comfyui/`, game/builder source and tools in `build/`, and generated runs/exports in `output/`. The user also requested a fourth root folder, `example/`, containing a portable complete workflow, example configuration, build runner, and a reviewed fictional asset bundle that can build a real game after installation. Keep root metadata and the npm wrapper at the root; do not restore the old mixed layout.
- Main workflow JSON files live in `comfyui/workflows/`. Accepted runtime source files live in `build/public/`; normal builds write and serve `output/game/`. Keep generated source bundles in `output/test-runs/`, CLI staging in `output/assets/generated/`, independent exports in `output/exports/`, and reports/backups in `output/diagnostics/`. `output/private-archive/` is ignored, never served and never copied into an export.
- Use cloud-hosted models for all model inference in this hackathon, including image generation. Build ComfyUI workflows with cloud/API model nodes rather than local model checkpoints.
- The included `example/` must build from its checked-in assets without a ComfyUI server, cloud login or paid generation. Regeneration is an explicit separate workflow with a fresh output directory and reviewed spending estimate. Preserve lossless sprite/chroma pixels when packaging source images, update manifest paths/hashes after conversion, and keep original generation runs under ignored `output/`.
- Do not download local model weights or configure local inference for this project unless the user explicitly changes this preference.
- This cloud-model preference does not itself authorize paid runs; follow the connected tools' spending-consent requirements.
- Build Comfy Fighter Z, an anime fighting-game asset factory and browser game. Keep the existing combat functionality and Comfy Fighter Z branding throughout the interface, workflows and documentation.
- The title screen reads Comfy Fighter Z with the subtitle Higgsfield Open Source Saga. Preserve the title, selection and two-fighter introduction flow; introTagline text and stock cloud voices come from the fighter configuration. Freeze combat during introductions and support skipping them.
- Keep local single-player versus CPU as the default. Also support invite-link online 1v1 and a shared display paired with one phone versus CPU or two phones versus each other. Each seat selects one fighter; keep the existing combat engine and its pose choreography (27 required key poses plus 18 optional arcade poses). Arrow keys move/jump/crouch; A punches, S kicks, D performs a heavy strike and F uses the one-button special. G taunts; A+S rolls, S+D blowback and F+D super. Single player defaults to Arcade: a CPU ladder ending with the final boss, with continues, endings and high scores. Local Versus with gamepads and Training are also available. The engine stays deterministic for server-authoritative play: no `Math.random` in the simulation. Use a full-viewport arcade layout with native fullscreen available from a user gesture. Multiplayer simulation is server-authoritative, with combat frozen during introductions and disconnects. Export a bundled Node server so multiplayer and QR pairing work with `npm start` without installing dependencies in the exported game.
- Use a restrained 1990s arcade presentation inspired by Neo Geo fighting games: charcoal, warm ivory, deep red, muted navy and brass accents, crisp panels and readable typography. Preserve the fictional character artwork and avoid importing reference-game characters, branding or private media.
- Shipped demo references, fighters and environments must be entirely fictional, generated from text with no real-person photos or real venue inputs. Preserve original private inputs outside versioned and served folders; never ship the earlier photo-derived sprites, film, source photos or screenshots as demo content.
- The optional opening supports a 25-second Seedance cloud video, mapped by `video.json` in a source bundle and `openingVideo` in the runtime manifest. Its default recipe uses seven `CFZFictionalReference` nodes to create fresh text-only references, with no `LoadImage` or external image files. Count those seven paid image calls in addition to the video charge. Only include a film made from fictional demo references. Play it before the title; Space skips directly to the title. Keep The Yard free of added speed-line borders.
- Also support an eight-second LTX cloud-generated opening and a separate animated title loop, mapped through `video.json` as `openingVideo` and `titleVideo`. Preserve support for the earlier 25-second opening. Use the game's fictional reviewed references, keep generation and costs explicit, and provide still-art fallback when motion is unavailable or reduced motion is requested. Generated movies and all existing character intro clips must survive the automated bundle and ZIP pipeline.
- Fighter introductions can optionally use silent LTX cloud-generated MP4 clips, mapped as `fighterIntros` in `video.json` and `introVideo` on runtime fighters. The main template generates them with `CFZIntroVideo`, one per fighter. It also makes the cast ensemble for the startup screen (`CFZTitleArt`, saved as the `ui/ensemble` image and shown for any cast) and its looping menu video (`CFZTitleVideo`, mapped as `titleVideo`). `CFZExportVideos` writes `video.json`. The asset lab lists every mapped video. Keep voices separate, pause videos and combat together, synchronize or skip introductions in multiplayer, and fall back to existing sprite entrances when clips are missing or fail. The included offline example must remain runnable without generating videos.
- The canonical arcade cast has six fictional parent-hero fighters, one fictional final boss (Baron Bylaw, `boss: true`, at most one per game) and three fictional arenas: The Yard, Sunset Rooftop and Midnight Arcade. The main generation template has six character factories, one final-boss factory and three environment factories, all enabled. Each supports text generation or an explicit new reference upload. Default to `Invent fictional reference` with empty image selectors. The reviewed complete example lives in `example/bundle/`; `npm run example` builds and installs it. It may be the classic release (six fighters, The Yard, 27 poses, 22 clips) or the complete arcade release (89 images, 99 clips, 45 poses). The example verifier accepts exactly one of those two contracts. Grow the classic bundle with `npm run workflows:expansion`, which reuses the accepted identities rather than redrawing them. Keep the lightweight canonical source preview separate from this included bundle. Never substitute The Yard for missing environment references. Keep factory configuration separate from the accepted runtime configuration; a newly built custom game can contain up to three environments.
- Keep the 27 required pose names in three 3x3 sheets (`sheets`) and the 18 optional arcade poses in two more (`extraSheets`: sheetD, sheetE) in `comfyui/config/game.json` compatible with the game's animation layer. Missing optional poses fall back to key poses at runtime. Generated art enters through a mapped `assets.json` bundle and the game builder, or the existing `comfyui/assets/plan.json` CLI pipeline; never silently substitute placeholder artwork in a strict release build. New bundles use `comfy-fighter-assets/v1` and `comfy-fighter-audio/v1`; earlier schema names are import compatibility details only.
- The main `comfyui/workflows/comfy-hackathon.json` is the compact factory template: project settings, six character factories, a final-boss factory, three environment factories, shared UI/effects, the startup ensemble, the menu video, one fight introduction per fighter, a final mapped `assets.json` and `video.json`. Custom nodes expand into native cloud nodes to generate fictional source designs, identity references, individual 3x3 sheets, portraits, heroes, super cut-ins, ending art and stage art. Invent mode uses 89 paid image calls for the full arcade cast (85 with one environment); explicit Upload mode uses 79 (77). The classic set (`include_arcade_art` off, no boss, The Yard only) uses 56. The startup media add 15 image calls and 16 silent 720p LTX clips (86 seconds, about $11.81) for seven fighters: a clash-style title key art with an 8 s menu loop (`CFZTitleArt`, `CFZTitleVideo`), an 8 s select-screen loop from the shared select backdrop (`CFZSelectVideo`, mapped as `selectVideo`), a portrait six-second idle-stance loop per fighter (`CFZSelectIdleVideo`, mapped as `selectIdles` / `idle-<fighter>`) that the select cards play with a beat of stillness between loops, and four-second shonen-style fight introductions that the game plays side by side on a split screen. The split-screen introduction is the only pre-fight screen. `CFZSpriteSheet` accepts an accepted sheet as `reference_sheet`; the character factory chains sheet A into B–E. The builder normalizes standing-pose heights per sheet against the idle cel, processes fighter sheets at native resolution, honors a reviewed `mirror` list on sheet records, and draws the arena at device resolution. The arena is drawn by `build/public/render/`: the vendored PixiJS v8 renderer (`vendor/pixi.min.js`, MIT, shipped with every export) when WebGL initializes, otherwise the Canvas 2D renderer; the HUD and callouts always draw on the 2D overlay canvas. `?renderer=canvas` forces the fallback and `FighterDebug.renderer()` reports the active one. The Pixi path carries the impact layer: a world shader (chromatic aberration, radial blur, shockwave ring, negative flash on supers and KOs), camera punch-ins, additive glow sparks, auras, speed lines and stage desaturation on KO. The game ignores prefers-reduced-motion on purpose. Keep `engine.js` and `anim.js` renderer-agnostic; see `port-pixi.md`. The muted `comfyui/workflows/factory/arcade-expansion.json` adds the arcade material to an accepted classic bundle with 33 image calls. `comfyui/tools/prepare-duo-run.cjs` prepares a complete two-fighter run with every image, the media and the audio for cheap end-to-end checks. Run paid API workflows on one-job workspaces with `comfyui/tools/run-sequential.cjs`. Keep individual sheet/character/environment templates usable and preserve the expanded graph under `comfyui/workflows/advanced/`. The builder loads the resulting JSON/folder and exports a self-contained game directory or ZIP.
- `comfyui/workflows/comfy-audio.json` generates music, announcer calls, effects and fighter voice lines through cloud nodes. It makes 99 clips: 10 music tracks, 20 announcer calls, 20 effects, and 7 lines per fighter (intro, special, super, attack, hurt, KO, win) in the configured stock voice. Write `audio.json` into the same root as `assets.json`; the builder includes both manifests and their source files in the exported game.
- Accepted runtime media in `build/public/assets/` is versioned. Normal builds must preserve it. Generate updates into separate source bundles, review the sprites, merge by asset ID, export and verify the complete game, then adopt the media. Keep credentials, raw test runs, build outputs and local MCP settings out of Git.
