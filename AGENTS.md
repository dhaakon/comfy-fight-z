# Hackathon project instructions

- Use cloud-hosted models for all model inference in this hackathon, including image generation. Build ComfyUI workflows with cloud/API model nodes rather than local model checkpoints.
- Do not download local model weights or configure local inference for this project unless the user explicitly changes this preference.
- This cloud-model preference does not itself authorize paid runs; follow the connected tools' spending-consent requirements.
- Build Comfy Fighter Z, an anime fighting-game asset factory and browser game informed by `C:/Users/dhaak/Development/dad-fighter-z-repo`. Treat that repository as read-only reference. Keep the existing combat functionality.
- The title screen reads Comfy Fighter Z with the subtitle Higgsfield Open Source Saga. Preserve the title, selection and two-fighter introduction flow; introTagline text and stock cloud voices come from the fighter configuration. Freeze combat during introductions and support skipping them.
- The game has one human-controlled fighter selected from the six-character roster, versus the CPU. Arrow keys move/jump/crouch; A punches, S kicks, D performs a heavy strike and F uses the special. Use a full-viewport arcade layout, with native fullscreen available from a user gesture. Keep the richer pose choreography in `public/anim.js` in exported games.
- Shipped demo references, fighters and environments must be entirely fictional, generated from text with no real-person photos or real venue inputs. Preserve original private inputs outside versioned and served folders; never ship the earlier photo-derived sprites, film, source photos or screenshots as demo content.
- The optional opening supports a 25-second Seedance cloud video, mapped by `video.json` in a source bundle and `openingVideo` in the runtime manifest. Its default recipe uses seven `CFZFictionalReference` nodes to create fresh text-only references, with no `LoadImage` or external image files. Count those seven paid image calls in addition to the video charge. Only include a film made from fictional demo references. Play it before the title; Space skips directly to the title. Keep The Yard free of added speed-line borders.
- The demo has six fictional parent-hero fighters and one fictional backyard arena, The Yard. The main generation template has six character factories and three environment factories; each supports text generation or an explicit new reference upload. Default to `Invent fictional reference` with empty image selectors. The Yard's text definition is enabled; the other two environments stay disabled. The fictional references and replacement assets are pending generation; save optional sample images under `ref/demo/` once generated and reviewed. Never substitute The Yard for missing environment references. Keep factory configuration separate from the accepted runtime configuration; a newly built custom game can contain up to three environments.
- Keep the 27 pose names and three 3x3 sheet layouts in `config/game.json` compatible with the reference. Generated art enters through a mapped `assets.json` bundle and the game builder, or the existing `assets/plan.json` CLI pipeline; never silently substitute placeholder artwork in a strict release build.
- The main `comfy-hackathon.json` is the compact factory template: project settings, six character factories, three environment factories, shared UI/effects and a final mapped `assets.json`. Custom nodes expand into native cloud nodes to generate fictional source designs, identity references, individual 3x3 sheets, portraits, heroes, cut-ins and stage art. Invent mode uses 56 paid image calls with one environment or 60 with all three; explicit Upload mode uses 49 or 51, respectively. Keep individual sheet/character/environment templates usable and preserve the expanded graph under `workflows/advanced/`. The builder loads the resulting JSON/folder and exports a self-contained game directory or ZIP.
- `comfy-audio.json` generates music, announcer calls, effects, character special calls and six intro taglines through cloud nodes (22 clips). Write `audio.json` into the same root as `assets.json`; the builder includes both manifests and their source files in the exported game.
- Accepted runtime media in `public/assets/` is versioned. Normal builds must preserve it. Generate updates into separate source bundles, review the sprites, merge by asset ID, export and verify the complete game, then adopt the media. Keep credentials, raw test runs, build outputs and local MCP settings out of Git.
